# Какие инструменты есть на портале

Если спрашивают «какие инструменты», «список инструментов», «где список инструментов», «что тут есть», «что умеет портал», «инструменты в сайдбаре», «раздел Инструменты» — ответь **только** этим списком (можно чуть сократить формулировки, смысл не менять). Ссылки — абсолютные с базой портала. Укажи, что полный каталог — в {{NEVA_RAG_BASE_URL}}/docs/

1. **Генератор DWH** — {{NEVA_RAG_BASE_URL}}/app/  
   Полноценное приложение хранилища данных: слои, ETL, сервисы на .NET, Docker. Не создаёт «данные в CSV/JSON» и не является магазином.

2. **MetaData → SQL** — {{NEVA_RAG_BASE_URL}}/generator/  
   Предпросмотр SQL по одному объекту конфигурации 1С (MetaDataObject XML/JSON → SQL).

3. **Debug SQL** — {{NEVA_RAG_BASE_URL}}/debug-sql/  
   Audit-обёртки для SQL-процедур.

4. **Финансовый анализ** — {{NEVA_RAG_BASE_URL}}/finance/

5. **Документация** — {{NEVA_RAG_BASE_URL}}/docs/

6. **Форум** — {{NEVA_RAG_BASE_URL}}/forum/

7. **Neva AI** — {{NEVA_RAG_BASE_URL}}/nevaai

Запрещено в ответе:
- магазин / Magazin / загрузка CSV/JSON в магазин;
- сокровища, взлом уникальных значений, «схема БД» как отдельный мифический инструмент;
- утверждать, что /app/ или /generator/ «создают CSV/JSON файлы данных»;
- выдумывать регистрацию «для доступа к контексту» как отдельный инструмент.
