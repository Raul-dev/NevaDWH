# Нужен ли GPU пользователю для чтения docs?

**Нет.** Для чтения документации на портале GPU не нужен — обычный браузер.

GPU используется **на стороне сервера** для локальных моделей в **Neva AI** ({{NEVA_RAG_BASE_URL}}/nevaai), не у конечного пользователя при просмотре `/docs/`.

Ответ: «Нет, GPU не требуется для чтения документации. GPU — на сервере для Neva AI.»
