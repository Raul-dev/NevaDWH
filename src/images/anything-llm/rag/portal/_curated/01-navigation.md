# Карта портала NevaDWH

Краткая навигация для ответов ассистента. Всегда давай прямую абсолютную ссылку на раздел.
Не выдумывай функции разделов. Не называй разделы «магазин», «сокровища», «взлом».

## Основное

- [Главная](/) — обзор платформы
- [О платформе](/about/) — что уже есть и куда смотреть дальше
- [Документация (каталог)](/docs/) — все статьи с описаниями

## Инструменты и сервисы (канон)

| Раздел | URL | Что это на самом деле |
|--------|-----|------------------------|
| Генератор DWH | `/app/` | Личный кабинет: из метаданных 1С генерируется **полноценное приложение DWH** (слои Landing/ODS/DWH, ETL, сервисы на **.NET**, выкладка в **Docker**). Это не выгрузка CSV/JSON и не «магазин данных». |
| MetaData → SQL | `/generator/` | Быстрый **предпросмотр SQL** по **одному** объекту MetaDataObject 1С (вход — XML/JSON описания объекта). Не создаёт всё хранилище и не «обновляет БД кнопкой». |
| Debug SQL | `/debug-sql/` | Добавляет **audit-обёртки** в текст SQL-процедуры. Не генератор DWH. |
| Финансовый анализ | `/finance/` | Прогнозы, графики, обучение моделей (Streamlit). |
| Сравнение моделей (док) | `/docs/model-comparison/` | MAE, RMSE, MAPE — сравнение моделей прогнозирования. |
| Форум | `/forum/` | Обсуждения и раздел Technical / База данных. Не «поиск сокровищ». |
| Neva AI | `/nevaai` | Страница входа к локальным AI-ассистентам портала. Не загрузка CSV в «магазин». |

Документация к инструментам:
- [MetaData → SQL](/docs/metadata-sql/)
- [Debug SQL](/docs/debug-sql/)
- [ROI генератора DWH](/docs/ttm-roi/)
- [Финансовая аналитика](/docs/analytics/)

## Важные различия

- **`/generator/`** = точечный SQL по одному объекту 1С.
- **`/app/`** = полный проект/приложение DWH (.NET + Docker), не CSV/JSON-экспорт.
- **`/nevaai`** = AI-чат, не хранилище файлов.
- **`/forum/`** = общение и статьи, не утилита unique values.
