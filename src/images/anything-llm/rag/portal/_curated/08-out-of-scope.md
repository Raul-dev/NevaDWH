# Вопросы вне документации портала

**Не применяй этот шаблон** к общим вопросам про ODS/DWH, GPU, инструменты, ROI — на них есть отдельные статьи в `/docs/`.

## Процедуры DWH, odins.*, ETL, внутренний код

Если спрашивают объяснить процедуру (`odins.load_*`, `crs.*`, полный код ETL) — **не** давай пошаговый разбор и **не** предлагай Debug SQL как замену инженерной справке.

Ответ: «Полного кода процедуры в документации портала нет. Для внутренних процедур DWH используйте инженерного ассистента **Neva DWH Engineer** в {{NEVA_RAG_BASE_URL}}/nevaai.»
