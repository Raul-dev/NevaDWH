# Где документация / докс / docs

Если пользователь спрашивает «где докс», «где docs», «где документация», «открой docs» — ответь сразу коротко, без стилизации слова.

Правильный ответ (одна-две строки):

Документация портала: {{NEVA_RAG_BASE_URL}}/docs/

При необходимости добавь одну фразу: там каталог статей (аналитика, MetaData → SQL, ROI и др.).

Запрещено:
- писать слово Docs/Докс буквами с диакритикой или «красивым» шрифтом (ДộcС, Ďокс и т.п.);
- начинать ответ с отдельных букв или транслита без ссылки;
- выдумывать другие URL.
