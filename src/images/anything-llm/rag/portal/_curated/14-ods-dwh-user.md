# Чем ODS отличается от DWH (для пользователя)?

По материалу {{NEVA_RAG_BASE_URL}}/docs/ttm-roi/:

- **ODS** — оперативный слой для **дневной активности**: быстрая фиксация текущих данных без тяжёлой истории.
- **DWH** — слой **истории и аналитики**: архив, витрины, отчётность; данные переносятся из ODS в периоды низкой нагрузки.

Это не отказ — отвечай по фактам из ttm-roi, не «в документации этого нет».
