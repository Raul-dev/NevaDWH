# MetaData → SQL



Инструмент в разделе [Инструменты → MetaData → SQL](/generator/) быстро превращает описание объекта конфигурации 1С (`MetaDataObject` в XML или JSON) в SQL-скрипты слоя ODS или в промежуточную модель таблицы.




## Для чего он нужен




      - Получить черновик DDL (CREATE TABLE) или процедур загрузки по одному объекту 1С — документ, справочник и т.п.

      - Проверить, как генератор сопоставляет реквизиты 1С с типами целевой СУБД (MS SQL, PostgreSQL, Oracle, ClickHouse).

      - Отладить конвертацию XDTO → таблица до сборки полного проекта DWH в личном кабинете (там уже ZIP всего хранилища по сохранённым «звёздам»).




MetaData → SQL — точечный предпросмотр по одному вставленному объекту. Полная генерация слоёв DWH/ETL для проекта — в сервисе **Генератор DWH** ([/app/](/app/)).




## Откуда взять MetaData




      - Выгрузка из панели администратора 1С (файл объекта конфигурации).

      - Конфигуратор: 1cv8.exe /DumpConfigToFiles — затем открыть XML нужного Document/Catalog.




На странице инструмента уже подставлен пример **Document.Продажи** — можно сразу нажать «Отправить в API» и посмотреть результат.




## Как пользоваться




      - Откройте /generator/.

      - Вкладка MetaData 1C(xml/json) — вставьте XML MetaDataObject или JSON-описание объекта.

      - Выберите СУБД: MS SQL / Postgres / Oracle / ClickHouse.

      - Выберите режим: Tables — DDL создания таблиц ODS.

          - Procedures — хранимые процедуры загрузки/staging.

          - MetaData — JSON-модель сущности (не SQL), удобно для проверки разбора.



      
      - По желанию нажмите Проверить связь (health API генератора).

      - Нажмите Отправить в API — результат откроется на вкладке Скрипт SQL.





## Что получается на выходе




      - Tables — текст CREATE TABLE под выбранный диалект.

      - Procedures — скрипты процедур под тот же диалект.

      - MetaData — JSON модели таблицы (имя, колонки, типы) после разбора XDTO.





## Ограничения




      - Один вставленный объект за раз — не весь проект конфигурации.

      - Нужен доступный API генератора (в проде — сервис dwhgenerator за Traefik).

      - Для полного ZIP DWH с авторизацией используйте Генератор DWH, а не эту страницу.





Открыть инструмент: [MetaData → SQL](/generator/).
