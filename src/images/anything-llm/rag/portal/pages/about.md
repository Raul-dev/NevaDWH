# NevaDWH



Платформа в активной разработке: мы строим среду, где команды смогут быстрее разворачивать и сопровождать корпоративные хранилища данных, а IT-стартапы — публиковать проекты и находить аудиторию.




Сейчас доступна ранняя версия: часть функций ещё в работе, интерфейс и документация будут дополняться по мере релизов.




## Что уже есть




        - Генератор слоёв DWH (ODS, DWH, ETL) из метаданных источника

        - Личный кабинет и API для работы с проектами

        - Форум для обсуждений, обратной связи и публикации стартапов

        - Docker- и k3s-окружения для локального и внутреннего тестирования
