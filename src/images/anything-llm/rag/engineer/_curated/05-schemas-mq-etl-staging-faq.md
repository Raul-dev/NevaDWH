# Какие роли у схем mq, etl, staging?

**Шаблон ответа:**
- **mq** — буферы и **очереди** сообщений (интеграция с MQ-сервисом).
- **etl** — процедуры загрузки и трансформации.
- **staging** — **промежуточные** таблицы перед target / ODS / DWH.
