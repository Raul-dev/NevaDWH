# Чем Landing отличается от ODS?

**Шаблон ответа:** **Landing** — сырьё из источника (1С, файлы, очереди), минимальная очистка. **ODS** — операционный слой дневной активности, актуальные срезы для отчётности.

Поток: источник → Landing → ODS → DWH.
