# Развертывание Сервера 1С:Предприятие 8.3 и СУБД PostgreSQL в Docker

Данный проект предназначен для локального развертывания полноценного серверного окружения 1С:Предприятие (версия 8.3.27) в связке с адаптированной СУБД PostgreSQL 18 на операционной системе Linux с помощью Docker и Docker Compose.

---

## 🛠 1. Подготовка и скачивание дистрибутивов

Перед началом сборки образов необходимо самостоятельно скачать дистрибутивы программного обеспечения с официального портала 1С. Из-за лицензионных ограничений эти файлы не могут быть включены в репозиторий автоматически.

### Шаг 1. Получение лицензии разработчика

1. Перейдите на портал [1С для Разработчиков](https://developer.1c.ru/).
2. Зарегистрируйтесь как физическое лицо и подтвердите номер телефона.
3. В личном кабинете в разделе **«Лицензии» → «Комьюнити»** запросите бесплатную комьюнити-лицензию.

### Шаг 2. Скачивание файлов

Скачайте необходимые дистрибутивы и поместите их строго в каталог проекта по пути `src/images/1C/`:

1. **Сервер приложений 1С:**

   * Ссылка: [developer.1c.ru/applications/Console?state=community](https://developer.1c.ru/applications/Console?state=community)
   * Найдите и скачайте: *«Технологическая платформа 1С:Предприятия (64-bit) для Linux»* версии **8.3.27.2130**.
   * Имя скачанного файла должно быть: `server64_8_3_27_2130.zip`
2. **СУБД PostgreSQL с патчами 1С:**

   * Ссылка: Там же на портале в разделе доступных дистрибутивов СУБД.
   * Найдите и скачайте: *«PostgreSQL для Ubuntu 24.04 (64-bit)»* версии **18.1-2.1c**.
   * Имя скачанного файла должно быть: `postgresql_18.1_2_ubuntu_24.04_x86_64_package.tar.bz2`

## 🏗 3. Пошаговая сборка Docker-образов

Сборка выполняется локально из директории `src/images/1C/`, где находятся ваши Dockerfile и дистрибутивы. Откройте терминал и выполните последовательно две команды.

### Шаг 1. Сборка СУБД PostgreSQL 18

Контейнер СУБД разворачивается на базе современной OS Ubuntu 24.04. В процессе сборки архив `.tar.bz2` автоматически распакуется внутри контейнера и установит нужные пакеты.

```rebuild
docker build --no-cache -t local-postgres-1c:18.1 -f src/images/1C/DockerfileDB src/images/1C/
```

```bash
docker build -t local-postgres-1c:18.1 -f src/images/1C/DockerfileDB src/images/1C/
```

### Шаг 2. Сборка Сервера приложений 1С (8.3.27)

В процессе сборки Docker автоматически распакует `.zip` архив платформы 1С и установит компоненты сервера, общие утилиты и настроит обязательную для работы русскую локаль (`ru_RU.UTF-8`).

```bash
docker build -t local-1c-server:8.3.27.2130 -f src/images/1C/Dockerfile src/images/1C/
```

По завершении сборки проверьте нал

## 🚀 4. Запуск и настройка Docker Compose

В корневой директории проекта создайте конфигурационный файл конфигурации `docker-compose.yml` со следующим содержимым:

```yaml
version: '3.8'

services:
  db-1c:
    image: local-postgres-1c:18.1
    container_name: db-1c
    environment:
      POSTGRES_DB: master
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: YourSecurePasswordHere # Укажите свой надежный пароль
    volumes:
      - pg_data:/var/lib/postgresql/data
    ports:
      - "5432:5432"
    restart: always
    networks:
      - network-1c

  server-1c:
    image: local-1c-server:8.3.27.2130
    container_name: server-1c
    environment:
      - DB_SERVER=db-1c
      - DB_USER=postgres
      - DB_PASSWORD=YourSecurePasswordHere
    ports:
      - "1540:1540" # Главный порт центрального сервера
      - "1541:1541" # Кластерный порт менеджер
      - "1560-1591:1560-1591" # Диапазон портов рабочих процессов
    volumes:
      - server_1c_data:/home/usr1cv8/.1cv8
      - server_1c_licenses:/var/1C/licenses # КРИТИЧЕСКИ ВАЖНО: Хранилище для комьюнити-лицензий
      - /etc/localtime:/etc/localtime:ro
    depends_on:
      - db-1c
    restart: always
    networks:
      - network-1c

volumes:
  pg_data:
  server_1c_data:
  server_1c_licenses: # Именованный том, защищающий лицензию от удаления при перезапуске

networks:
  network-1c:
    driver: bridge
```

### Команда для запуска контейнеров:

Запустите окружение в фоновом режиме (detached mode):

```bash
docker compose -f docker-compose.1C.yml up
```

Проверить статус запущенных контейнеров и отсутствие ошибок можно командой:

```bash
docker compose ps
# Или посмотреть логи сервера 1С:
docker compose logs -f server-1c
```

## 🔑 5. Активация комьюнити-лицензии разработчика

Благодаря выделенному тому `server_1c_licenses`, ваша лицензия **не удалится** при перезапуске или обновлении контейнеров (`docker compose down / up`).

1. Запустите вашу локальную консоль 1С (Тонкий или Толстый клиент) на рабочем компьютере.
2. Добавьте новую базу, выбрав тип подключения **«На сервере 1С:Предприятия»**.
3. Укажите параметры:
   * Кластер серверов: `localhost` (или IP-адрес Docker-хоста)
   * Имя информационной базы: Любое имя (например, `test_db`)
4. При первом подключении система сообщит об отсутствии лицензии и откроет мастер активации.
5. Выберите пункт **«Активировать комьюнити-лицензию»** и введите учетные данные (логин и пароль) от вашего аккаунта на сайте `developer.1c.ru`.

Программа автоматически свяжется с сервером лицензирования 1С и сохранит файл лицензии в защищенную папку внутри контейнера. Приятной разработки!
